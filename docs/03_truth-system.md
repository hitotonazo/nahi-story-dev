# 1. 真相の中心

真相ページは、

「冬霞ヶ関駅という超常現象の研究資料」

を主役にしない。


主役は、

人物抹消業務
「Rルート」

の運用計画書・実施記録。


Rルートは、

国家機関

大企業

巨大組織

その他の依頼主

から依頼を受け、

対象者を確保

↓

移送

↓

凪燈ものがたりへ搬入

↓

山間ルートへ進入

↓

冬霞ヶ関駅で一人だけ降車

↓

消失確認

までを行う業務。


霧嶺運行サービス株式会社は
実行部隊・運行管理側。


対象者を決定する
最終的な依頼主ではない。
